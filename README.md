## Publish through GitHub and Cloudflare Pages

1. Extract this ZIP on your computer.
2. Open the extracted project folder in GitHub Desktop or VS Code.
3. Commit and push the updated files to the GitHub repository connected to your NV SHARP SOLUTIONS Cloudflare Pages project.
4. Cloudflare Pages will publish the commit according to the connected project’s existing build settings.

For a static Pages project with no framework, the build command is usually blank and the output directory should match the repository’s configured static root. Keep the existing project settings when pushing this update.
